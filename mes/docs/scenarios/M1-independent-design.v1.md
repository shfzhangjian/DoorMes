## S — 场景与范围

设计人员无需先造销售需求，即可新建独立门窗设计，进入原生画布自定义分格、尺寸、构件和材质，保存到后端，从图纸中心重新打开完整设计。人工图号、名称、备注与几何一起保留版本；程序内部 UUID 与人工编号分开。

| 账号 | 角色 | 用途 |
| --- | --- | --- |
| `design`（1003） | 设计研发 | 新建和保存本人独立图纸 |
| `admin`（1001） | 管理员 | 代修、另一个独立设计创作者 |
| `sales`（1002） | 销售 | 查询；无设计创建/保存权限 |
| `reviewer`（1007） | 审核 | 只读查询；越权否定断言 |

密码只在脚本内读取忽略 Git 的 `runtime-local/factory-bootstrap/accounts.local.json`；不写密码、Token 或登录响应到场景输出。不能重置账号、组织、菜单或权限来通过测试。

| 字段 | API / SQL | 规则 |
| --- | --- | --- |
| 图号 | `metadata.number` / `dm_drawing.drawing_number` | 当前工厂内不区分大小写唯一，可人工维护 |
| 名称、备注 | `metadata.name/note` / `dm_drawing.name/note` | 版本保存，历史不随最新 head 变动 |
| 来源 | `metadata.source` / `source_type` | 独立图固定 `INDEPENDENT`，不能伪装来源 |
| 内部身份 | `id`、`document.designId` | 不因人工图号变化而改变 |
| 创建请求 | `clientRequestId` / `create_request_id/create_payload_hash` | 租户 + 创作者内幂等，变更参数拒绝 |
| 完整几何 | `document` / `drawings/tenant-1/<UUID>/rN.json` | 使用与前端相同的共享引擎校验 |
| 可编辑 | `editable` | 根据当前账号、所有权、当前版本即时计算 |

## A — 断言与边界

- 不能用页面按钮或本地存储代替成功创建/保存：必须有服务器 ID、SQL head/version、完整版本 JSON。
- H2 和实时 MySQL 不混用。12 个 `DrawingStandaloneTest` 另覆盖租户隔离、自动编号、权限撤销、规范化后目录/资产引用、回滚与损坏文件；旧 5 个 `DrawingServiceTest` 需求流程不得退化。
- 模型原始引用和共享引擎规范化结果均验证，不能在字段丢弃后绕过目录/资产门禁。
- HTTP 不能验收动画白屏、画布尺寸遮挡、标记布局、3D 闪动或实际 WebGL；这些留待人工操作。
- 浏览器实际操作可验收上述界面约束，证据需单独记录截图/操作结果；后端 45 条断言通过不代表界面操作通过。
