PRE-03：使用受控 TEST 图纸；优先只读复用 `TEST-UI-20261003` 历史样本。需要保存新样本时使用新的 TEST 编号，不覆盖用户设计。不触发采购、生产、外部通知。

## 首轮实际记录（2026-10-03）

- 当前版 R3：1350×1500，贯通竖梃分成两格；历史 R1：1200×1500，无竖梃。两版 SVG 文本与 1:20 外框几何反算一致。
- 实际下载的 R3 ZIP 有两页：图形页、独立组成件表页。ZIP 的图形页与单独下载的 SVG 相同。三份 SVG 均通过 XML 解析，A3 横向 420×297 mm。

- 打印入口生成同版本两页 A3 文档，并实际触发 `beforeprint`。无实体打印任务；无头浏览器不能据此证明操作系统打印窗口或“另存 PDF”人工交互已通过。
- 失败 F-01：R3/R1 切换偶发失败，重复操作又成功。只读接口观察显示首请求业务码 401、刷新后重试业务码 0，但界面收到旧 401 响应而不是重试后的解包数据。归因为请求库异步错误恢复丢失返回值；禁止用重试按钮或在业务页面反复取 `.data` 掩盖。
- 原始 `S1-acceptance.webm` 保留首次录制及排查，39:21.72、1280×720、VP8、无音轨。它包含登录准备空画面、长停顿、失败与后续成功，不作为精简介绍视频。`00-forward-slash.mp4` 是录制环境空白试片，不算验收证据；`07-hmr-load-failed.png` 是热更新触发错误，不是未保存宽度通过截图。
