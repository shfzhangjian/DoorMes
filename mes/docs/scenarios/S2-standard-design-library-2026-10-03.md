# S2 企业标准设计库阶段记录

日期：2026-10-03。基础仓库分支：`handoff/mes-migration-20261003`。

## 本次范围

- 在当前工厂内把独立设计的**已保存图纸版本**提交审核；审核员不能审批自己的提交。
- 发布版本保持原图纸 JSON 和 SHA-256 索引不变。图纸后续修订可再次提交；新版本审核期间旧发布版仍可复用。
- 审核驳回、停用均记录原因与操作人。停用及版本更换后，旧版本不得新建复用副本。
- 不同设计账号可把现行发布版复用为新的独立草稿图纸；新图纸编号、ID、文件、版本独立，数据库记录来源图纸及版本。
- 当前仅支持独立设计入库，不含组件库、需求图纸转标准、产品适用范围、会签及正式制造发布。

## 数据和部署

新库迁移为 `db/doormes/V007_standard_designs.sql`，需在 V006 之后应用，且仅适用于隔离的 `doormes_local`。本机 `127.0.0.1:33306` 已应用并验证两张标准库表、三项岗位权限和来源字段。旧机数据库未写入。本机服务已用 `local,doormes` profile 运行；旧机版本文件仍待复制，因此旧图纸暂不能提交审核或复用。

设计员权限：`doormes:design:standard-submit`、`doormes:design:standard-reuse`（复用还需 `drawing-create`）；审核员：`doormes:design:standard-review`。接口位于 `/admin-api/doormes/standard-designs`，使用当前租户权限和保存版本身份校验。图纸中心列表的操作菜单可提交，右上角进入标准设计库；默认只看现行已发布版，审核员可切换全部版本并审批或停用。
