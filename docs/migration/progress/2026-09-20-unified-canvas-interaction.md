# 统一2D画布命中与交互意图

日期：2026-09-20  
对应版本：DoorMes 0.10.32  
任务：UI-2D-007  
状态：共享功能完成，真实鼠标/触控手感及浏览器E2E继续验收

## 1. 本轮目标

在普通推拉增加轨道、多活动扇和更多操作手柄前，先把现有2D交互从分散的DOM事件判断收口为稳定的共享规则。PC与移动端仍采用各自布局和呈现方式，但不再各自判断“点到了什么、应该选择还是拖动”。

## 2. 已完成内容

### 2.1 无DOM共享解析器

`interaction-core`新增画布命中和意图纯函数，不依赖SVG、浏览器DOM、Three.js或业务算法：

1. 命中优先级固定为“可拖动手柄 → 工程尺寸 → 普通业务对象 → 画布空白”；
2. 输入统一归约为`select`、`drag`、`pan`、`edit-dimension`、`open-properties`或`context-menu`；
3. 鼠标、触控笔、触摸和键盘可以复用相同意图，不把端类型写入领域模型；
4. 解析器只决定交互意图，正式设计修改仍由既有共享命令提交。

### 2.2 点击、拖动与平移仲裁

- 主指针累计移动不足6px时保持待定点击，不立即进入拖动或平移；
- 贯通梃、拓扑梃、飞梃/固定中梃交汇构件只有越过阈值后才显示拖动预览；
- 从画布空白、玻璃、窗扇、普通窗体或尺寸开始并越过阈值均可进入视图平移；只有显式构件/抓手进入结构拖动；
- 手势一旦越过阈值，后续指针帧以零阈值保持已确定的拖动/平移意图，即使指针回到起点附近也不会卡住或闪回点击；
- 拖动或平移完成后的浏览器兼容`click`会被抑制，避免松手时误选对象；
- 点击抑制从`pointerup`后再释放，慢速拖动不会因计时器提前结束而失效；
- SVG继续永久禁止原生文字拖选。

### 2.3 属性、尺寸和上下文操作

- 单击统一选择对象，空白单击清空选择；
- 双击工程尺寸继续打开精确数值编辑器；
- 双击普通对象或拖动手柄统一发出`open-properties`：PC滚动并聚焦右侧属性区，移动端展开并聚焦全屏属性抽屉；
- Enter/空格对可聚焦命中使用同一双击意图，保留键盘入口；
- 桌面右键和移动550ms长按使用同一`context-menu`意图；
- 只有贯通梃和拓扑梃允许进入现有删除/位置菜单，飞梃和固定中梃交汇构件不会误入该菜单。

## 3. 代码边界

- `packages/interaction-core/src/canvas-interaction.ts`：命中、阈值和意图纯函数；
- `packages/ui-components/src/index.ts`：把SVG节点适配成共享命中，管理临时拖动/平移预览，并在松手时调用既有命令；
- `packages/layout-shell-desktop/src/index.ts`：仅负责PC属性面板的滚动和焦点呈现；
- `packages/layout-shell-mobile/src/index.ts`：仅负责移动属性抽屉的展开、滚动和焦点呈现。

该分层确保后续普通推拉只需声明新轨道/面板的命中类型和命令，不需要复制一套桌面与移动判断逻辑。
