# 多窗与安装规划的0.10.39定界说明

日期：2026-09-20  
原对应版本：DoorMes 0.10.33  
当前状态：已补充组合窗默认放置、方向确认、包边接缝和连接件规则；以[三模式工作空间与变更流](../workspace-modes.md)、[门窗工厂设计制造范围与实施顺序](./2026-09-20-factory-manufacturing-scope.md)及`docs/migration/todo.md` 0.10.39为权威计划

## 1. 保留的判断

“画面上有多个窗格”不能统一叫多窗，正式设计仍须区分：

1. **一樘窗、一个连续外框**：多个固定格、开启扇、中梃或飞梃仍属于同一`WindowUnit`；
2. **实际物理拼樘产品**：多个单樘通过拼樘料、角柱、连接件、加强和密封形成共同制造/交付的产品，属于`FabricationAssembly`；
3. **同订单但无物理连接的独立窗**：可以共同参与批量备料、下料优化和发运分组，但产品结构、生产号和包装身份保持独立。

相邻显示、同一墙面或同一订单都不能自动推导物理连接。只有用户显式进入“组合窗/拼樘”工具时，“增加窗”才默认吸附到当前选中单樘，并且必须在落位前确认左/右/上/下方向、连接类型、间隙和厂内/现场拼接范围；普通设计画布的新增窗仍保持独立。

## 2. 已撤销的执行方向

0.10.33曾计划先建设完整的项目墙体、洞口、窗安装实例和两墙转角空间，再继续普通推拉。根据产品面向门窗工厂的定位，该顺序会过早进入建筑安装深化，并使制造核心依赖现场对象，因此不再执行。

门店模式可建立轻量房间/墙面、名义或实测洞口、整体预览和基础安装记录，但这些对象属于`StoreProjectDocument`，通过已发布产品ID和交付安装接口关联，不能改写单樘制造模型。完整建筑BIM、复杂墙体网络、跨专业深化和多承包方施工编排仍转为`SITE-001/002`后置任务。

## 3. 当前组合模型

- `WindowUnit`：单樘局部毫米制造模型；
- `WindowUnitInstance`：组合中的唯一产品/生产实例；
- `FabricationAssembly`：工厂供货组合及其相对坐标；
- `EngineeringJoint`：直线/上下/转角连接、间隙、材料、加工和工艺；
- `factoryScope`：厂内组装、分体交付或现场按工厂节点连接；
- 包装拆分：定义哪些实例同包、分包或使用托架。

墙厚、洞口、框位、室内外和安装间隙只作为产品交付包络，供2D俯视、3D预览、开启碰撞和随货安装物料使用，不成为组合产品的权威空间。

## 4. 组合窗交互与连接件规则

### 4.1 默认增加行为

1. 组合窗模式下先选择一樘宿主窗，再点击“增加组合窗”；
2. 新窗默认与宿主相连，但必须选择或确认`left/right/top/bottom`，不得只靠屏幕坐标猜测；
3. 预览吸附线、总体尺寸和单樘尺寸，确认后才创建`WindowUnitInstance + EngineeringJoint`；
4. 取消连接时保留独立单樘，不生成拼樘料、连接件、密封或组合工艺；
5. 转角连接不复用左右直线拼樘，须明确夹角、角柱/转角料和室内外方向。

0.10.47实现状态：PC和移动端已经在创建表单提供上述四向确认，并区分“独立窗、拼樘连接、加强拼樘、上下叠接”和连接件成品宽度。当前选择的窗体、框、扇、玻璃、五金或组合实例均可解析为连接基准；无选择时只回退到最近创建窗并在结果区提示。创建新窗和建立/追加组合按一个原子事务执行，一次撤销全部恢复，任一端口、尺寸、对齐或包络校验失败时不会留下孤立窗。当前矩形首切片要求左右等高、上下等宽；L形、跨多樘整行叠接和转角仍分别留给后续批量落位/ASSEMBLY-003，界面不能把失败组合静默降级为独立窗。

### 4.2 包边经过连接缝时

- 默认外周连续包边只计算组合产品外轮廓，内部连接边不重复包边；
- “各樘独立包边”作为显式备选，用于分体交付或现场独立收口；
- 接缝可独立设置缝宽、衬板收口、密封胶条/胶、盖缝件及颜色/材质型号；
- 左右/上下连接改变哪些边属于外周，任何变更都必须使相关包边BOM、连接BOM和尺寸标注过期重算。

### 4.3 连接件不是渲染装饰

`EngineeringJoint`至少保存连接端口对、方向、连接类型、净缝、连接型材/加强料型号、紧固件套件、密封件、加工模板和组装范围。参考类型包括直线拼樘料、加强拼樘料、上下连接料、转角柱/角码、螺钉/拉铆件、连接片、密封胶条和盖缝件。2D显示节点符号和尺寸，3D显示实际连接构件；EBOM、孔槽/端铣、组装顺序、质检和包装均引用同一连接ID。

## 5. 当前开发顺序

1. 完成包边/衬板与五金业务型号到渲染、物资和工艺的映射；
2. 完成技术目录维护和设计业务选型；
3. 收口当前固定/开启/双扇/上悬的尺寸、材质、包边和3D选择显示；
4. 建立`FabricationAssembly`最小契约、四向吸附确认、包边外周规则和`EngineeringJoint`连接件目录；
5. 以“一樘开启窗 + 一组左右直线拼樘”贯通2D/3D、材料映射和连接BOM，再补上下拼接；
6. 继续普通推拉和其余原型窗型，每个窗型接入同一组合与材料链；
7. 后续增加转角窗/飘窗等工厂组合产品；
8. 工厂制造闭环完成后，再决定是否启动完整现场安装工程。

## 6. 人工验收边界

- 同一连续外框不得产生拼樘料；
- 无物理连接的独立窗不得因为靠近而自动连接；
- 确认拼樘后才生成连接料、加强、密封、加工特征和包装拆分；
- 相同规格的实例仍有不同产品/生产号；
- 工厂组合可在没有建筑墙体模型时完成2D、3D、BOM、工艺和包装；
- 开启校核使用交付安装包络，但墙体显示本身不改变窗本体BOM。
- 组合窗模式新增时必须看到左/右/上/下方向确认；普通新增窗不得被静默连接；
- 外周连续包边不得在内部拼缝重复计料，连接件必须在2D、3D、BOM和工艺中使用同一连接ID。
