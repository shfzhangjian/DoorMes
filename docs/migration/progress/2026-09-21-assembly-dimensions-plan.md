4. 组合内开启扇仍调用共享运动内核，俯视轮廓、关闭虚线、角度弧线和角度文字读取真实预览角度；没有第二套组合专用角度算法。

## 上下组合截面规则

首版截面高取第一实例中心高，并通过`data-section-y-mm`记录。只有穿过该高度的窗实例和连接区进入俯视，避免把上下叠接的不同高度构件错误叠在同一个平面。后续工程出图阶段可增加可移动剖切线、多截面编号和打印图签；该交互不会改变组合结构或BOM。
