# 单件五金选择与型号覆盖

版本：0.10.17  
日期：2026-09-18  
状态：功能实现完成，等待用户人工交互与视觉确认

## 本次关闭的问题

此前领域快照允许使用`role + hardwareId`覆盖单件五金型号，SVG、Three和工艺解析也会优先读取该覆盖；但界面拾取只返回所属开启扇或飞梃ID，对象树也只显示五金汇总，因此用户无法真正创建这类配置。这属于“数据能力存在、用户功能断链”，已登记为`AUD-ASSET-002`。

## 已实现

1. 2D五金图元的选择身份改为稳定`hardwareId`，同时通过`data-opening-object-id`保留所属开启扇回链。
2. 3D五金模型及其子网格使用同一个`hardwareId`参与拾取和选中轮廓，同时保留`openingObjectId`、连接ID、安装目标及型号元数据。
3. 对象树在原五金连接汇总下列出执手、合页叶、锁点、锁座、操作杆和天地插销等单件，PC与移动复用同一树投影。
4. 共享外观/型号编辑器识别当前选择；选中五金后自动切到其业务角色，并提供“该角色全部构件（默认型号）”和“仅当前构件”两个应用范围。
5. 参数化型号、审核目录型号及GLB/glTF导入均支持两个应用范围。单件编辑写入精确覆盖，不修改角色默认值或同角色其他实例。
6. 精确覆盖继续通过`resolveHardwareComponentModel`进入SVG、Three、开启碰撞包络、安装锚点和加工特征；目录批准的单件型号可携带自己的物资编码及加工模板，预览草稿仍不能冒充可生产型号。

## 人工确认建议

人工测试由用户在页面完成：分别从2D、3D和对象树选中一个执手或合页，确认三处同步高亮；在属性面板选择“仅当前构件”并更换型号，确认同角色其他五金不变；再切换“该角色全部构件”验证默认型号批量生效。该人工步骤不会由自动浏览器操作代替。
