# 三投影与工程图纸近期执行计划

文档版本：0.8.0  
日期：2026-09-21  
状态：SHEET-001已完成，SHEET-002总装图已可页内预览、下载SVG及打印/另存PDF

## 1. 已确认目标

DoorMes只维护一份门窗设计模型，并从中生成三种职责明确的投影：

1. **2D工程设计投影**：服务绘制、选择、尺寸约束、构件关系、传统开启图示和俯视编辑；
2. **3D真实仿真投影**：服务材质/纹理/玻璃/五金外形、开合运动、装配位置、参考安装环境、运动包络和碰撞验证；
3. **工厂/安装技术图纸投影**：服务审核、打印、加工/组装和安装指导，使用纸空间尺寸、线型、符号、编码、材料表和标题栏。

三种投影共享对象ID、毫米几何、开启机构、材料/型号快照及BOM来源。任何投影不得扫描显示节点重新算尺寸、连接、洞口或物料。

## 2. 3D仿真范围

当前必须实现：

- 真实PBR材质、纹理、透明玻璃和不同型号五金/自定义GLB；
- 窗扇按实际角度与真实铰接关系运动；
- 单窗、组合窗、连接件、包边和参考墙/洞口的装配位置；
- 开启包络以及与墙体、包边等毫米障碍体的碰撞；
- 可控制显隐并按当前选择收敛的尺寸、角度和诊断覆盖层。

当前不声称实现结构有限元、抗风压、热工、隔声、水密/气密等专业计算。这些能力未来必须由独立计算模块、材料性能目录和版本化规范规则提供，不能从渲染结果推断。

## 3. 技术图纸规则

- 工厂图重点：产品总装/分格、总体/分段/局部尺寸、构件与材料编码、加工/组装节点、BOM/明细、标题栏和版本；
- 安装图重点：墙体/洞口、框位、间隙、锚固、密封、包边、室内外、剖面/节点和现场说明；
- 尺寸采用“局部靠近图形、分段居中、总体最外”的通道顺序，并按图幅和比例使用纸面毫米间距；
- 关闭立面使用传统开启符号；实际运动角度与弧线放在俯视/剖面或3D仿真覆盖层；
- 黑白打印必须可读。材料以编码、规格、表面处理代码、标准填充和材料表为权威；彩色效果页或3D快照只作附件。

## 5. 近期里程碑与门禁

- `MS-02`：现有固定/平开/双扇/上悬绘图与交互一致性；
- `MS-02A`：组合窗、连接件、包边外周和制造映射；
- `MS-02B`：三投影职责、3D真实仿真边界和正式出图基础；
- `GATE-DRAWING-OUTPUT`：A3/A4及指定比例黑白图纸无遮挡、编码可追溯、工厂/安装图职责正确；
- `GATE-3D-SIMULATION`：真实材质/模型、运动、装配/安装空间、碰撞和辅助覆盖层通过人工检查。

## 6. 本阶段不实施

- 采购、排产、销售订单和安装任务执行系统；
- 登录、账号、角色、权限、审批和正式审计；
- 完整建筑BIM；
- 结构、抗风压、热工、隔声、水密/气密专业计算；
- 仅为了效果展示而复制第二套门窗模型、尺寸公式或BOM逻辑。

## 7. 当前实现进度

0.10.54完成了`SHEET-001`第一层：

- 新增独立`@doormes/drawing-model`，不依赖浏览器DOM、SVG、Canvas或Three；
- 建立`DrawingSheet`、`DrawingView`、线性尺寸及符号/材料/构件/备注标注Schema；
- 支持A4/A3、横竖版、来源设计revision、视图比例和图幅边界校验；
- 技术图纸尺寸按比例换算为纸面毫米，固定首道距离和通道间距；
- 按“局部、分段、总体”顺序占用由内到外的完整标注带，同层尺寸再按尺寸跨度和文字宽度避让；
- 现有组合窗SVG通道分配改为复用同一纯算法，但保留当前屏幕交互像素间距，未直接把交互画布冒充打印图纸；
- 自动基线为21个测试文件、220项测试；类型检查、冻结BOM夹具和生产构建通过。

0.10.55继续完成：

- `@doormes/drawing-projection`从共享设计/几何直接生成独立窗或连接组合的`factory-sheet`快照；
- 总装线稿包含框、扇、玻璃、梃、连接区、精确组合外轮廓和传统开向图示；
- 净尺寸、分樘尺寸和组合总尺寸使用同一纸空间层级布局；
- `@doormes/renderer-drawing-svg`输出A3物理图幅、黑白线宽、材料说明、比例、来源revision和标题栏；
- 设计器顶部增加“导出工厂图”；选择组合根、实例、连接件或组合内构件时统一导出完整组合，独立窗保持独立；
- 出图模块使用动态加载，不读取交互SVG、3D相机或屏幕缩放；
- 自动基线更新为24个测试文件、225项测试。

0.10.56继续完成：

- `DrawingSheet`增加纸空间`DrawingTable`、列、来源行和严重级别，表格位置/列宽/行数均在模型层校验并冻结，不由SVG临时拼接业务数据；
- 工厂图只保留“门窗设计组成件”表：无当前计算时显示型材、玻璃、五金及包边选型摘要；有同revision计算时展开逐件组成及加工尺寸。正式MBOM、生产状态和工序不在总装图表格中混排，转入后续制造包；
- 投影器可选接收带来源revision的`FormalBomResult`，只在revision与图纸设计完全一致时打印MBOM；缺失时标记“仅供设计选型核对”，过期时拒绝打印旧物料并输出`BOM-STALE`；
- MBOM行直接来自计算引擎的制造特征/物料行并回链全部来源ID，同物料、规格和尺寸可在纸面聚合；连接件材料优先保留在首张明细，超页以明确“另有N行”提示，不静默截断；
- 连接件表从`EngineeringJoint`和正式EBOM/工序特征输出连接ID、类型、缝隙、工厂/现场范围、规则版本及钻孔/组装模板；
- SVG适配器以黑白/灰阶表格渲染，长文本限制在单元格视口内并保留完整`title`与来源数据属性，不覆盖相邻列；
- 当前设计器尚未加载企业正式制造目录，因此顶部导出会明确报告“设计选型版（正式MBOM待工厂目录）”，没有用演示色彩或参考模型伪造生产物料；
- 自动基线更新为24个测试文件、227项测试；类型检查、冻结BOM夹具和生产构建通过。

0.10.57继续完成：

- 表格标题、表头、正文的字号与行高进入`DrawingTable.layout`物理纸空间模型，SVG/PDF适配器必须读取同一值；正文提升至3mm（约8.5pt），尺寸文字提升至3mm，并扩大文字背景与碰撞估算；
- 表格按标题栏前的可用页高分配行数，空间不足时继续打印明确的“另有N行”，不再靠缩小字体把内容硬塞入一页；
- 立面上的材料长文本已移除，业务选型和正式物料继续只在右侧可追溯表格中表达，避免和净宽、分樘尺寸重叠；
- 工厂图新增第二个`plan`视图：框截面、连接区、关闭虚线轮廓、实际设计开启轮廓、起始/当前射线、虚线角度弧和度数均由共享`WindowSectionDimensions`及`opening-kinematics`生成；
- 俯视图固定`+Z`室外位于纸面上方、室内位于下方，并标注“室外↑/室内↓”；组合窗按实例X/Z位置投影为一个整体，不为每樘重复生成方向基准；
- 工厂图使用保存设计中的目标开启角，不读取当前3D相机、播放进度或临时预览状态；A3自动缩放为立面与俯视共同留出可读空间。

0.10.59继续完成：

- 设计器顶部入口从“直接下载”改为“预览工厂图”，在独立有界对话框内查看整张A3/A4图纸，不挤压2D/3D设计工作区；

- 移动小屏使用全屏预览壳和可横向检查的最小图幅，不复制图纸投影或排版算法；
- 自动基线更新为24个测试文件、229项测试；类型检查、冻结BOM夹具和生产构建通过。

0.10.60继续完成：

## 8. 已登记的后续选择对象图包

`SHEET-005`在总装图、正式BOM作用域和工艺路线稳定后实施，不插入当前字体/俯视与打印适配收口：

1. 用户可从2D、3D或对象树选择整窗、制造组合、组合实例、框/扇/梃、玻璃、单件五金、连接件、包边或衬板；
2. 选择结果只提交稳定对象ID，由共享`DrawingScopeResolver`解析父子装配、制造特征和配合接口，禁止从SVG或Three对象反推；
3. 按对象类型生成适用的正投影、俯视、剖面/节点或爆炸装配关系，并带入基准、尺寸、公差、材料型号和表面处理；
4. 图包附带同revision的局部正式EBOM/MBOM、下料/孔槽/安装参数、工艺模板和逐件生产号；
5. 随货备件、维护备件和易损件使用独立版本化备件规则，不通过给主BOM数量任意加一实现；
6. 选择父对象默认覆盖可制造后代；选择子对象只输出自身和必要配合参考，配合参考件必须标明“不属于本图供货范围”；
7. 缺目录、计算快照、工艺模板或备件映射时输出设计核对版与明确诊断，不允许标记为可下发制造包。
