# 组合连接制造映射进度（0.10.49）

日期：2026-09-21  
范围：ASSEMBLY-002 / BOM-008 直线拼樘与上下叠接制造映射首片

## 本次目标

将已经用于2D、俯视和3D的`EngineeringJoint`升级为正式生产来源。组合内各单窗仍按既有规则计算，不因建立组合而重复窗框、玻璃或五金；连接新增物料和工序仅归属连接ID。

## 已完成

- 新增可替换的`EngineeringJointManufacturingRule`目录契约；目录未显式提供时使用三个版本化预设，显式数组代表工厂自定义目录并整体替换预设。
- 普通拼樘产生连接型材、按最大400mm间距计算的紧固件、双侧连续密封和双面盖缝料。
- 加强拼樘在上述物料之外增加通长镀锌钢加强衬料，并采用更密的300mm紧固间距。
- 上下叠接按水平连接实际长度产生独立料号，紧固件最大间距为350mm。
- 连接长度来自`resolveFabricationAssemblyGeometry`的毫米矩形长边，连接间隙来自持久化`gapMm`；计算器不读取SVG、Three Mesh或屏幕包围框。
- 每条连接生成`engineering_joint` EBOM、角色化制造特征、MBOM、采购汇总、型材下料和计划生产号。
- 每条有效连接生成带模板ID的紧固件钻孔与连接组装工序；工序引用材料特征，不额外生成物料行。
- 删除`FABRICATION_ASSEMBLY_RULES_PENDING`统一阻断。只有连接目录缺失/不完整或工艺模板缺失才阻断生产确认；材料完整但工艺缺失时仍可审计MBOM。

## 规则示例

1500mm普通竖向拼樘：

- 连接型材：1500mm净长，1504mm下料长，1件；
- 紧固件：`max(2, ceil(1500/400)+1)=5`件；
- 密封：双侧路径3000mm，即3m；
- 盖缝料：1500mm净长，2件；
- 工序：5点钻孔、1次连接组装。
