# 五金安装轴与枢轴编辑

版本：0.10.18  
日期：2026-09-18  
状态：功能实现完成，等待用户人工观察不同轴向的3D贴合效果

## 业务目的

不同供应商的GLB/glTF原点、朝向和安装面并不一致。源单位、上轴和朝外轴解决“文件坐标如何进入DoorMes”；型号的安装朝向轴与枢轴则解决“归一化后的实体如何贴到扇、框、飞梃或固定中梃”。两层配置不可混为一组，否则同一个模型在不同安装位置会被迫重复上传。

## 已实现

- 角色默认型号和单件型号表单都可编辑真实宽、高、深（毫米）。
- 参数模型与受控模型导入步骤都可选择`±X/±Y/±Z`六向安装朝向轴。
- XYZ枢轴比例均可输入0..1：0表示声明包络的最小边，1表示最大边；例如`0.5/0.5/0`表示后表面中心。
- 选择目录预设会同步回填尺寸、安装轴和枢轴，不会残留前一个草稿的安装参数。
- 手工修改或导入仍降为`preview-only`，避免旧物资编码或加工模板错误沿用。
- Three模型定位、开启碰撞体、安装Z坐标和加工特征继续读取同一型号快照，不从显示网格反算。
- 领域归一化现会在运行时拒绝未知安装轴；枢轴比例继续严格限制在0..1。

## 验证

- TypeScript严格检查通过。
- 18个测试文件、161项测试通过。
- 无效安装轴和越界枢轴自动拒绝。
- 既有跨层工艺测试继续证明型号枢轴与安装轴进入正式安装/加工特征。

## 人工确认建议

在页面选中一个执手，使用“仅当前构件”，分别切换`+Z/-Z/+X/-X`并应用，观察3D朝向变化；再把Z枢轴从0改到1，确认模型沿自身深度改变贴合面，但同角色其他五金、窗扇运动角和BOM兼容结果不变。人工视觉测试由用户执行，不由自动浏览器操作代替。
