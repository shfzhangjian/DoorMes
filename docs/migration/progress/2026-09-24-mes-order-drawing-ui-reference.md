# 门窗MES订单图纸设计交互参考

文档版本：0.1.4

日期：2026-09-24

参考资料：用户提供的本地门窗MES操作视频（约31分31秒）

状态：已完成全时轴抽帧审查和关键设计片段复核；作为交互参考，不作为业务规则或生产数据来源

## 1. 结论

视频最有价值的不是传统Windows界面样式，而是以下业务交互链：

`订单明细 → 打开门窗图纸 → 参数化设计 → 选择型材/玻璃/五金 → 确认设计 → 保存图纸缩略图与稳定身份 → 算料/生产继续引用同一设计`

DoorMes当前仍以绘图可视化和材料映射为主线，不建设完整销售订单、算料调度或生产执行页面。近期只吸收能够改善工厂设计工作台的交互原则，并为未来订单行引用设计快照保留稳定契约。

## 2. 纳入DoorMes的交互原则

1. **图形模板优先**：创建区按产品族和开启机构展示可识别的图形模板，不要求设计人员先理解底层拓扑或渲染参数。
2. **画布是主工作区**：立面保持主视图，俯视/截面和3D按任务切换或作为辅助视图，不持续挤压主图比例。
3. **尺寸直接编辑**：总尺寸、分格尺寸和净尺寸继续使用现有稳定对象ID；单击选择、双击编辑、拖动构件重算约束。
4. **业务属性检查器**：普通工厂设计人员只看到系统/型号、内外表面、玻璃构成、五金套系、安装方式、数量、编号和备注。
5. **目录选择器独立**：型材、玻璃、五金和辅件通过编号、名称、规格、适用范围和预览选择；PBR、UV、纹理哈希、GLB轴向/枢轴及工艺模板归技术目录维护。
6. **一次确认形成原子修改**：连续草稿调整可以预览，最终“应用设计”只提交一个可撤销命令边界，不能留下半次拓扑或半次目录选择。
7. **设计缩略图与稳定身份贯穿下游**：未来订单行、算料和生产页面只引用已保存的设计revision、产品/实例编号和缩略图，不复制几何或重新解释SVG。
8. **型材目录可带3D截面/模型预览**：预览用于确认选型，设计人员不直接编辑网格；正式加工仍依赖审核过的截面、物资和工艺版本。

## 3. 明确不照搬的内容

- 不复制密集小字号、无分组图标、横向超宽表格和多层模态窗口；
- 不把订单头、审批、算料状态、排产和生产调度塞进绘图工作台；
- 不在图面打印产品全称、主动/从动等内部角色文字，图面继续以稳定编号、尺寸和行业开向符号为主；
- 不允许业务选型界面直接编辑技术渲染参数或从屏幕颜色反推物料；
- 不以视频中的示例型号、尺寸、公式或生产字段作为智宬轩正式数据。

## 4. 与当前里程碑的结合

### MS-02 / MS-02A：先关闭现有绘图门禁

- 复核固定、内开内倒、外开、双扇、上悬、共面组合和连续转角；
- 重点检查2D尺寸/开向、俯视、3D接缝/闪动、参考墙/包边和跨视图选择；
- 发现差异只修共享模型、投影或交互，不建设订单页面。

### OPEN-001：普通推拉作为下一完整纵向切片

普通推拉首片同时验证新的工厂设计工作台基线：

1. 模板面板能够选择智宬轩公开参考的110/120推拉模拟族；
2. 支持2–6扇、1–5活动扇、2–4轨的共享参数模型，六轨后续扩展；
3. 轨道、滑扇、固定扇、交叠边、锁闭件具有稳定对象ID和直接选择/尺寸编辑能力；
4. 右侧以业务属性和目录选择为主，技术目录编辑从普通入口隐藏；
5. 2D材质图、工程线稿、俯视、3D运动、对象树、材料映射和保存恢复消费同一设计快照；
6. “应用设计”作为一次原子命令提交，撤销不留下半成品；
7. 输出设计缩略图和未来订单行可引用的`designId/revision/productTemplateSnapshot`，但不实现订单表格和销售流程。

## 5. 下一项工作与退出标准

下一项工作不是包装运输或生产调度，而是：

`GATE-DRAWING-PARITY + GATE-3D-SIMULATION + MS-02A转角视觉门禁 → 修正差异 → OPEN-001普通推拉纵向切片`

启用目标客户推拉模板并进入视图集成前必须确认：

- 现有目标模板的2D、俯视、3D、选择、尺寸和恢复没有阻断缺陷；
- 连续两转角在多视角下无Z-fighting，窗框/角柱接触和墙/包边接缝稳定；
- 工程线稿与材质图均可读，交互辅助层不会混入图纸；
- 业务目录快照、禁止投产诊断和稳定编号链保持有效；
- 自动测试、类型检查和生产构建继续通过。

中性的滑扇/轨道数据契约、领域校验和毫米线性运动不依赖目标产品的视觉签审，允许先行建立。0.11.2完成这一基础，0.11.3进一步接入`WindowCell`、共享命令、撤销及严格项目保存恢复；0.11.4解析等宽扇闭合包络、设计搭接、扇距、单步行程和抽象轨道中心面；0.11.5让2D立面、俯视和3D共用稳定扇号、轨道中心面与毫米平移，并补齐选中滑扇的宽高、最大行程和型材说明。中性工厂入口、材料/五金和BOM仍未接入，供应商轨槽和不等宽/级联规则不得猜测，目标模板继续保持失败关闭策略。

## 6. 后续保留接口

未来订单模块只需要保存并展示以下引用，不要求绘图核心依赖订单：

- `orderLineId`（由未来订单域拥有）；
- `designId`与`designRevision`；
- `productTemplateSnapshot`；
- `manufacturingIdentityRoot`；
- `drawingThumbnailRef`；
- 当前尺寸、面积、数量和状态摘要的只读投影。

因此未来可以实现“订单行打开图纸、确认后回填摘要”，同时保持绘图核心、订单域和生产执行域相互解耦。
