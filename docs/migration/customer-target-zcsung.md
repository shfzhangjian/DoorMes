# 智宬轩目标客户与产品模板范围

文档版本：0.1.4  
日期：2026-09-22  
状态：目标客户已确认；公开资料基线已建立，生产数据待企业确认

## 1. 目标客户确认

DoorMes当前目标客户固定为**智宬轩系统门窗**。本项目近期仍是门窗绘图可视化与材料映射工具，但窗型、构件、业务目录、制造映射和验收夹具均应优先以该企业公开产品体系为模板模拟，不再以无来源的通用演示窗型作为产品路线依据。

公开资料表明，该企业同时覆盖系统窗、系统门和阳光房，并从事研发、设计、生产、运营及安装服务。因此当前“工厂设计优先、门店安装为输出支撑、开发定义后置”的产品边界保持不变，但目录和窗型优先级必须改由目标企业产品谱系驱动。

## 3. 模板模拟原则

1. **以产品族建模，不以页面截图硬编码。** “101漂移内倒”“95M微通风”等应成为带版本的业务模板，引用共享框、扇、梃、轨道、纱网、五金、运动和制造映射能力。
2. **营销系列与工程系统分层。** 莲花1865、天都、玉屏等是业务展示维度；型材系统、玻璃、五金、密封、表面处理和加工模板是工程目录维度，两者通过适用规则映射。
3. **公开资料只生成仿真模板。** 在企业正式图册和技术数据未导入前，模板统一标记`public-reference/simulated`，不得标记“目录已审核”“可投产”或输出可信加工坐标。
4. **2D、3D、BOM同源。** 每个企业产品模板仍只实例化DoorMes共享对象图；不得为某一系列复制一套SVG、Three或BOM算法。
5. **图面不展示内部操作角色文字。** P1/P2、主动/从动、操作顺序和五金宿主保留为内部语义与对象元数据；立面只显示行业开向图示、角度、尺寸和必要构件标识，避免把内部角色名称印在产品图上。
6. **阳光房单独建域。** 阳光房需要三维空间骨架、屋面、立柱、梁、排水、连接节点和围护填充，后续应建立`ConservatoryAssembly`类能力，不以超大异形窗替代。

## 4. 目标客户驱动的开发顺序

| 顺序 | 目标切片 | 原因与完成边界 |
| --- | --- | --- |
| Z0 | 收口现有固定、内开内倒、外开、双扇、梃、组合窗 | 自动矩阵已覆盖三个模板的2D/俯视/3D/外观/BOM；按`acceptance/Z0-ZCSUNG-001.md`完成PC/移动人工视觉签审后退出 |
| Z1 | 普通推拉及多轨系统 | 目标企业公开目录中推拉窗/门和六轨景观窗占比高；先完成2–6扇、1–5活动扇、2–4轨，再扩到六轨模板 |
| Z2 | 95M微通风、95S双内开及门纱一体 | 在现有平开核心上增加通风档位、组合开启、纱网/纱扇、互锁和对应五金映射 |
| Z3 | 提升推拉、漂移内倒和景观侧压 | 复用轨道/面板核心，增加提升、压紧/脱离密封面、多阶段运动和专用五金 |
| Z4 | 极窄吊轨/平开门、折叠门和重型门 | 增加门槛、吊轨、承重、通行扇、折叠链、门锁及门类制造约束 |
| Z5 | 全景幕墙窗与电动提升窗 | 增加大分格、幕墙节点、电机/控制/限位和安全诊断接口 |
| Z6 | 平斜顶、人字顶、异形顶阳光房 | 建立独立空间装配模型后再进入，不抢占单樘门窗绘图主线 |

### 4.1 当前可执行模拟入口

0.10.76新增`@doormes/product-template-catalog`，目录与绘图算法保持分离。当前仅下列模板具有可执行中性预设：

| 模板ID | 公开产品依据 | 当前映射 | 状态与限制 |
| --- | --- | --- | --- |
| `ZCSUNG-SIM-LH-120-TT@0.1.1` | 120内开内倒系统窗 | 单扇内开内倒共享模型；AL70/HW-TT-STD参考目录 | 可模拟；尺寸、型材面宽、角度和五金均为DoorMes中性值 |
| `ZCSUNG-SIM-YK-100-OUT@0.1.1` | 迎客之星100外开及其他公开外开系列 | 单扇侧平开外开共享模型；AL70/HW-TURN-STD参考目录 | 可模拟运动与图形；不同系列不得因此共享正式截面/BOM |
| `ZCSUNG-SIM-YP-95S-DOUBLE-IN@0.1.1` | 玉屏95S双内开系统窗 | 固定中梃双扇内开；AL70/HW-TT-STD参考目录 | 部分模拟；官网未证明中梃/飞梃及五金组合，必须等待企业确认 |

除浏览器人工入口`?demo=zcsung-120-inward-tilt`、`?demo=zcsung-100-outward`和`?demo=zcsung-95s-double-inward`外，0.10.77已把三个模板接入PC左侧创建区和移动创建面板的“产品模板”选择。设计人员可覆盖中性宽高；独立创建以一个事务写入窗体与开向，连接创建则严格按“创建窗体→配置开向→建立连接”原子提交，撤销不会留下半成品。设计标记含“公开参考模拟”，属性面板在选择窗体、单元、扇、梃或五金时显示业务产品名、精确模板版本和“禁止投产”，但不暴露PBR、截面假设等开发字段。

目录状态固定为`simulated-not-for-production`。选择后，精确模板ID、版本、产品名、官方来源URL和中性假设会形成不可变快照随窗体及项目文件保存；正式BOM仍可用于核对映射，但会产生`PRODUCT_TEMPLATE_NOT_PRODUCTION_APPROVED`阻断诊断，不能确认投产。

0.10.78建立Z0自动验收矩阵：上述三个模板均从正常应用创建计划实例化，并逐一检查2D尺寸、室内外/开向、俯视实际角度、3D框/扇/中梃、共享外观和参考BOM。AL70、HW-TT-STD与HW-TURN-STD只用于让现有DoorMes参考计算链可核对，不代表智宬轩正式型材或五金。短期0.1.0版本曾使用制造目录不存在的占位编码；恢复项目时仅在同时识别到确切占位ID后迁移为0.1.1，其他历史快照不改写。

0.10.79补齐`docs/migration/acceptance/Z0-ZCSUNG-001.md`人工签审包。三个模板各自使用隔离的本地快照作用域和重置入口，测试人员按单步动作记录PC/移动2D、俯视、3D、选择与恢复结果；证据目录不预置伪造截图，人工结论未填写前Z0不标记完成，普通推拉不提前启动。

普通/多轨推拉、提升推拉、漂移内倒、景观侧压、微通风、门、幕墙、电动提升和阳光房已经登记模板及缺失能力，但当前没有可执行预设。调用方会明确拒绝，而不是用普通平开窗或简单位移动画近似。

## 5. 企业必须补充的正式资料

以下数据未在公开产品页中形成可投产定义，必须由目标企业提供并确认版本：

- 产品系列技术图册、适用尺寸/重量、开启角与组合限制；
- 框、扇、梃、轨道、压线、转换框等型材截面DWG/DXF或参数化截面；
- 型材、玻璃、隔热条、胶条、纱网、连接件、紧固件、包边和表面处理物资编码；
- 五金套系、供应商型号、承重/行程、安装锚点、孔槽/端铣模板和替代规则；
- 玻璃构造、厚度、垫块、嵌入量和最大板幅/重量规则；
- 下料、扣减、拼接、角码、加强、排水、密封、组装、质检及包装算法；
- 设备、刀具、工位能力和生产/安装交付格式；
- 企业对系列命名、有效版本、停用替代和图纸/BOM签审的最终口径。

在这些资料未齐之前，DoorMes可以验证几何、交互、运动、外观、目录映射和规则接口，但输出必须继续带“参考/模拟/禁止投产”诊断。
