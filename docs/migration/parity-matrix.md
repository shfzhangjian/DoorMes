## 细化规则

每一行进入迁移前必须继续拆分：

1. 原型入口、操作步骤和截图编号。
2. 输入数据、前置状态和领域命令。
3. 设计JSON差异、2D视觉差异、3D场景差异和BOM差异。
4. PC与移动布局分别验收，核心结果只维护一份预期值。
5. 原型缺陷必须引用审计编号，不能用“一致性”隐藏或延续未批准错误。
