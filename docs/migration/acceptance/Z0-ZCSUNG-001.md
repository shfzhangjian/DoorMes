## S - 场景

### 测试目标

确认120内开内倒、迎客之星100外开、玉屏95S双内开三个公开参考模拟模板，在PC和移动交互壳中共用同一窗体模型、开向、尺寸、选择和材质数据；2D立面、俯视、3D仿真及业务身份没有明显错位、遮挡或错误近似。

本签审只确认绘图、运动、交互和参考材料映射。模板必须持续显示“公开参考模拟 · 禁止投产”；不确认智宬轩正式截面、物资编码、孔槽或算料规则。

### 业务范围

- 产品模板创建与来源身份；
- 2D材质图、工程线稿、尺寸、开向符号、角度弧和俯视；
- 3D框、扇、玻璃、中梃、五金、开合与地面室内外方向；
- 2D/3D/对象树选择联动和属性区业务名称；
- PC与移动壳共用同一数据结果；
- 自动门禁已覆盖的外观及参考BOM不在人工界面重复计算。

### 前置约束

- 使用Node.js 22及项目当前依赖启动`npm run dev`，确认终端显示5173端口就绪。
- 每个案例使用带`resetProject=1`的专用URL，清除的仅是该演示场景本地设计快照，不影响其他场景、GLB文件或视觉历史。
- 不修改账号、权限或审批配置；当前没有这些功能。
- 不把AL70、HW-TT-STD或HW-TURN-STD称为客户正式工程目录。
- 人工结果和截图必须在执行后填写；准备阶段保持空白。
