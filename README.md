# DoorMes

## 2026-10-03 迁移交接入口

实际工厂 MES 前后端及内嵌绘图引擎已安全归档到 [`mes/`](./mes/SAFE-IMPORT.md)，仓库原有绘图项目保留。接续开发先阅读[场景进度与迁移交接](./docs/handoff/README.md)。2026-10-04 已补充指定图纸运行文件包；数据库、凭据和其他私有资料仍须另行安全迁移，不在 Git 中。

下面的绘图项目能力清单保留原阶段记录，不能据此认定实际 MES 的所有业务已交付，或正式制造目录和下料审核已经完成。当前业务完成度以交接文档的场景状态为准。

DoorMes是由 `luck_door` 原型升级而来的正式门窗设计与制造项目。当前处于迁移阶段，原型仍是界面和功能一致性的参照，正式项目按共享领域核心、PC交互壳和移动交互壳逐步接管能力。

当前目标客户已确认为**智宬轩系统门窗**。窗型、构件、材料/五金目录和验收夹具将优先按其公开产品谱系建立明确标记的模拟模板；在企业正式型材截面、物资编码和加工规则导入前，不把公开宣传资料冒充可投产工程数据。详见[目标客户与产品模板范围](./docs/migration/customer-target-zcsung.md)。

## 当前已完成

- npm workspaces与TypeScript严格检查。
- 共享设计快照和稳定对象ID。
- 版本化墙/框/扇/玻璃/包边外观快照，以及五金参数化/GLB型号、实际尺寸、枢轴、LOD和角色/精确构件覆盖基础。
- PC/移动共享真实GLB/glTF导入，包含自动SHA-256、格式/外链/复杂度预检、本地目录/IndexedDB持久保存、进度与审核证据；未发布导入保持仅预览。
- 可替换模型上传网关与项目本地目录；附带四个官方成功模型及两个拒绝样例的工人测试包。登录、权限、审批和操作审计在功能迁移完成后实施。
- 两步授权/原始字节上传/描述查询HTTP客户端；开发环境同源API默认写入`runtime-data/visual-assets`，部署时可切换正式HTTP服务。
- 本地模型按资产ID+SHA-256重新读取并进入Three运行时注册表；桌面使用高清LOD，移动优先使用低清LOD，失败时保留可见降级体和状态提示。
- 正式设计按场景本地自动保存，并在PC/移动头部提供同一严格格式的“保存项目/导入项目”，用于跨端口、跨浏览器备份与恢复。
- 材质与五金参数在PC/移动共享编辑器中即时预览2D/3D；预览不修改正式设计、BOM、自动保存或撤销历史。
- 每樘窗在本地保留最近20个去重材质/型号版本，可先预览历史，再作为一条可撤销正式命令恢复。
- 目录批准的框、扇、中梃和飞梃内/外/侧面可生成版本化表面处理工艺；普通颜色、PBR、纹理和显示编码不影响BOM。
- 共享制造输入指纹和BOM状态可区分纯展示修订与生产变更，统一支持未计算、当前、过期和重算语义。
- 材质纹理横/纵重复支持任意0.001–1000正数倍率，未绑定纹理时也会保存并在后续绑定后生效；2D SVG交互面已禁止浏览器原生文字拖选。
- 当前PBR、UV、哈希和模型参数面板明确为迁移期高级目录工具；最终设计流程将只选择业务材质、玻璃、型材和五金型号，底层渲染/模型/生产映射由独立维护功能承接。

## 开发命令

```text
npm install
npm run dev
npm run typecheck
npm test
npm run build
```

启动开发页面后，在地址后附加 `?demo=topology` 可查看T形拓扑，附加 `?demo=opening` 可查看单扇内开内倒，附加 `?demo=double-opening` 可查看可调飞梃双扇，附加 `?demo=fixed-mullion` 可查看固定中梃双扇。空间组合入口为 `?demo=corner-assembly`，连续三樘两转角凸窗链入口为 `?demo=multi-corner-assembly`。目标客户模拟入口为 `?demo=zcsung-120-inward-tilt`、`?demo=zcsung-100-outward` 和 `?demo=zcsung-95s-double-inward`；其尺寸和截面均是明确标记的DoorMes中性演示值，不是企业审核参数。人工验收时可再附加 `&shell=desktop` 或 `&shell=mobile` 固定布局壳；默认运行仍自动响应屏幕和指针。该页面用于迁移阶段验证，不代表原型完整界面已经迁移。

## 架构原则

```text
共享领域模型、命令、几何、渲染、BOM和工艺
                 ↓
        PC布局壳        移动布局壳
```

布局壳只负责布局、导航和输入翻译，不得包含构件几何、BOM或工艺规则。
